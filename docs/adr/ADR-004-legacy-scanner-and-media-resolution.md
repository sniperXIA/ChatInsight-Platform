# ADR-004: 聊天扫描解析与多模态媒体关联策略

## 状态
已采纳 (Accepted)

## 上下文
微信群历史导出格式中可能存在文件名明确的媒体（如 `[adff814f849adec972b9c52a05807612.mp4]`）以及不确定的占位符（如 `[图片]`）。

## 决策
1. 建立基于行扫描的高容错 Legacy TXT 解析器，支持多行消息、中文冒号、表情、引用标记识别，对异常格式行不丢弃并记录诊断信息。
2. 明确文件名的媒体按精确文件名匹配，置信度设为 `1.0`，关联状态标记为 `confirmed`。
3. 历史 `[图片]` 占位符采用时间窗口与顺序启发式算法生成候选关联；仅在单一唯一候选时可达高置信度，多候选或存在冲突时标记为 `needs_review`，严禁作为未确认确定证据直接发布。
4. 每次导入前提供预检质量报告（Precheck Report），详细列出消息数、媒体数、歧义数与警告项。
